## What this is

A fully installed SMF 2.1.7 forum, filled with generated content, dumped
for both database engines. It exists to be the starting point for testing the
SMF 2.1 -> 3.0 upgrade: restore it, point a 3.0 checkout at it, run upgrade.php.
